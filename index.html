1. Análisis Avanzado con Pandas: Exploración y Limpieza (EDA)

En esta sección inicial, descargamos y cargamos el dataset de ciberseguridad para verificar su integridad, tipos de datos, nulos y duplicados, cumpliendo con los estándares de la guía oficial de Pandas.

import pandas as pd
import kagglehub

# 4. Detección de valores nulos
print("\n--- COMPROBACIÓN DE VALORES NULOS ---")
print(df.isnull().sum())

# 5. Detección de registros duplicados
print("\n--- COMPROBACIÓN DE DUPLICADOS ---")
print(f"Número de filas duplicadas: {df.duplicated().sum()}")

# 6. Resumen estadístico general (describe)
print("\n--- DESCRIPCIÓN ESTADÍSTICA GENERAL ---")
print(df.describe())

2. Análisis Técnico: Agrupaciones y Tablas Dinámicas

En esta sección aplicamos operaciones de análisis avanzado utilizando agrupaciones (groupby), tablas dinámicas (pivot_table) y filtrado condicional (loc) para extraer conclusiones del tráfico de ciberataques.

# 1. Agrupación (groupby): Conteo de ataques según su tipo (Attack Type)
print("\n--- RESUMEN POR TIPO DE ATAQUE (groupby) ---")
attacks_by_type = df.groupby('Attack Type').size().reset_index(name='Total_Ataques')
print(attacks_by_type)

# 2. Tabla dinámica (pivot_table): Cruce entre Tipo de Ataque y Acción Tomada (Action Taken)
print("\n--- TABLA DINÁMICA: ATAQUE VS ACCIÓN TOMADA ---")
pivot_action = pd.pivot_table(
    df, 
    index='Attack Type', 
    columns='Action Taken', 
    values='Source Port', 
    aggfunc='count', 
    fill_value=0
)
print(pivot_action)

# 3. Filtrado avanzado (loc): Aislar registros de alta severidad o un protocolo específico
# (Filtramos, por ejemplo, los registros cuyo puerto de destino sea menor o igual a 1024 - puertos bien conocidos)
critical_attacks = df.loc[df['Destination Port'] <= 1024]
print(f"\n--- FILTRADO AVANZADO (.loc) ---")
print(f"Número de ataques dirigidos a puertos <= 1024: {len(critical_attacks)}")
print(critical_attacks[['Timestamp', 'Source IP Address', 'Destination Port', 'Attack Type']].head())

3. Visualización de Datos

En esta sección añadimos gráficos optimizados con etiquetas de valor para apreciar con precisión las pequeñas diferencias entre categorías.

import matplotlib.pyplot as plt import seaborn as sns

Configuramos el estilo visual

sns.set_theme(style=“whitegrid”)

Gráfico 1: Conteo de ataques por tipo con etiquetas de datos numéricos

plt.figure(figsize=(10, 5)) ax = sns.countplot(data=df, y=‘Attack Type’, order=df[‘Attack Type’].value_counts().index, palette=‘viridis’)

Añadir los valores exactos al final de cada barra

for p in ax.patches: width = p.get_width() ax.annotate(f’{int(width):,}‘, (width, p.get_y() + p.get_height() / 2.), ha=’left’, va=‘center’, fontsize=11, color=‘black’, xytext=(5, 0), textcoords=‘offset points’)

plt.title(‘Distribución de Ataques por Tipo (Conteo Exacto)’) plt.xlabel(‘Número de Registros’) plt.ylabel(‘Tipo de Ataque’) # Ajustamos ligeramente el límite del eje X para que los números no queden cortados plt.xlim(0, max(df[‘Attack Type’].value_counts()) * 1.1) plt.tight_layout() plt.show()

Gráfico 2: Frecuencia según el Nivel de Severidad con etiquetas

plt.figure(figsize=(8, 5)) ax2 = sns.countplot(data=df, x=‘Severity Level’, palette=‘Set2’)
