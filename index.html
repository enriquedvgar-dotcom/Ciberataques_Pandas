0.1 1. Introducción y Contextualización del Dataset

En este proyecto de la asignatura de Administración de Sistemas (ASIR), realizamos un análisis exploratorio de datos (EDA) centrado en la monitorización y detección de tráfico malicioso en red. Para ello, utilizamos Pandas, Matplotlib y Seaborn en un entorno controlado con Python, integrando los resultados a través de Quarto.

El conjunto de datos analizado proviene de la plataforma Kaggle (Cyber Security Attacks), diseñado para simular eventos de seguridad recopilados por sistemas de detección de intrusiones (IDS/IPS) y Firewalls en una infraestructura corporativa.

0.1.1 📌 Variables Clave del Dataset

Para contextualizar el análisis desde la perspectiva de un Administrador de Sistemas y Analista de SOC (Security Operations Center), se identifican las siguientes variables técnicas: * Timestamp: Marca temporal en la que se registra el evento de red. * Source IP Address / Destination IP Address: Direcciones IP de origen (potencial atacante) y destino (servidor o equipo de la red interna). * Source Port / Destination Port: Puertos lógicos de comunicación. Es vital diferenciar entre puertos efímeros y puertos bien conocidos (\(\le 1024\)), ya que estos últimos albergan servicios críticos (HTTP, HTTPS, SSH, FTP, DNS). * Attack Type: Tipología del incidente registrado (ej. Malware, DDoS, Intrusion). * Severity Level: Nivel de criticidad atribuido al evento (Low, Medium, High). * Action Taken: Respuesta o medida defensiva ejecutada por el sistema (Blocked, Ignored, Logged).

0.2 2. Exploración Inicial y Calidad de Datos (EDA)

En esta primera fase se evalúa la integridad y consistencia del dataset. La presencia de registros duplicados o valores nulos no tratados en logs de auditoría puede distorsionar las métricas de incidentes e impactar en las políticas automatizadas de seguridad.

import pandas as pd import kagglehub import glob import os

1 1. Descarga y localización automática del dataset desde Kaggle

path = kagglehub.dataset_download(“teamincribo/cyber-security-attacks”) csv_files = glob.glob(os.path.join(path, “**“,”*.csv”), recursive=True) csv_file_path = csv_files[0]

print(f”Archivo cargado correctamente: {os.path.basename(csv_file_path)}“)

2 2. Carga del DataFrame

df = pd.read_csv(csv_file_path)

3 3. Estructura general del dataset (tipos de datos y memoria)

print(“— ESTRUCTURA GENERAL DEL DATASET —”) print(df.info())

4 4. Verificación de valores nulos o incompletos

print(“— COMPROBACIÓN DE VALORES NULOS —”) print(df.isnull().sum())

5 5. Detección de registros duplicados

print(“— COMPROBACIÓN DE DUPLICADOS —”) print(f”Número de filas duplicadas: {df.duplicated().sum()}“)

6 6. Resumen estadístico inicial (describe)

print(“— DESCRIPCIÓN ESTADÍSTICA GENERAL —”) print(df.describe())

7 1. Agrupación (groupby): Conteo global por tipo de ataque

print(“— RESUMEN POR TIPO DE ATAQUE (groupby) —”) attacks_by_type = df.groupby(‘Attack Type’).size().reset_index(name=‘Total_Ataques’) print(attacks_by_type)

8 2. Tabla dinámica (pivot_table): Relación cruzada entre Tipo de Ataque y Acción Tomada

print(“— TABLA DINÁMICA: ATAQUE VS ACCIÓN TOMADA —”) pivot_action = pd.pivot_table( df, index=‘Attack Type’, columns=‘Action Taken’, values=‘Source Port’, aggfunc=‘count’, fill_value=0 ) print(pivot_action)

9 3. Filtrado avanzado (.loc): Aislar tráfico dirigido a puertos críticos (<= 1024)

critical_attacks = df.loc[df[‘Destination Port’] <= 1024] print(f”— FILTRADO AVANZADO (.loc) —“) print(f”Número de ataques dirigidos a puertos bien conocidos (<= 1024): {len(critical_attacks)}“) print(critical_attacks[[‘Timestamp’, ‘Source IP Address’, ‘Destination Port’, ‘Attack Type’]].head())

import matplotlib.pyplot as plt import seaborn as sns

10 Configuración del tema gráfico

sns.set_theme(style=“whitegrid”)

11 Gráfico 1: Distribución por Tipo de Ataque con recuento exacto

plt.figure(figsize=(10, 5)) ax = sns.countplot( data=df, y=‘Attack Type’, order=df[‘Attack Type’].value_counts().index, palette=‘viridis’ )

12 Etiquetas numéricas en el extremo de cada barra

for p in ax.patches: width = p.get_width() ax.annotate(f’{int(width):,}‘, (width, p.get_y() + p.get_height() / 2.), ha=’left’, va=‘center’, fontsize=11, color=‘black’, xytext=(5, 0), textcoords=‘offset points’)

plt.title(‘Distribución de Ataques por Tipo (Conteo Exacto)’, fontsize=14, pad=15) plt.xlabel(‘Número de Registros’, fontsize=12) plt.ylabel(‘Tipo de Ataque’, fontsize=12) plt.xlim(0, max(df[‘Attack Type’].value_counts()) * 1.15) plt.tight_layout() plt.show()

13 Gráfico 2: Frecuencia según el Nivel de Severidad

plt.figure(figsize=(8, 5)) ax2 = sns.countplot( data=df, x=‘Severity Level’, palette=‘Set2’ )

for p in ax2.patches: height = p.get_height() ax2.annotate(f’{int(height):,}‘, (p.get_x() + p.get_width() / 2., height), ha=’center’, va=‘bottom’, fontsize=11, color=‘black’, xytext=(0, 5), textcoords=‘offset points’)

plt.title(‘Frecuencia de Eventos según el Nivel de Severidad’, fontsize=14, pad=15) plt.xlabel(‘Nivel de Severidad’, fontsize=12) plt.ylabel(‘Cantidad de Incidentes’, fontsize=12) plt.ylim(0, max(df[‘Severity Level’].value_counts()) * 1.15) plt.tight_layout() plt.show()
